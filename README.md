# bakeevx

Личное портфолио на Astro и TypeScript. Статическая сборка, шрифты и изображения размещаются вместе с сайтом.

## Запуск

Требуется Node.js 22.12+ (проверено на 24.19).

```sh
npm ci
npm run dev
```

Проверка: `npm run check`, сборка: `npm run build`, просмотр сборки: `npm run preview`.

## Замена контента

Основной файл: `src/data/content.ts`. Массив `projects` задаёт порядок на главной, в каталоге и в переходах между кейсами: детейлинг, оклейка, корейский, воркшоп, это портфолио. Не сортируйте его отдельно в шаблонах.

У каждого проекта можно изменить `name`, `summary`, `role`, `task`, `solution`, `steps`, `outcome`, `metrics`, `period` и `gallery`. `contact` задаёт Telegram для всех контактных кнопок. Услуги и FAQ находятся здесь же.

Изображения находятся в `public/images`. Сейчас интерфейсы в `Mockup.astro` являются демонстрационными композициями. Для настоящих скриншотов используйте поля `coverImage` и `image` у элементов `gallery`; укажите путь к файлу и подпись `imageAlt`. Если изображения не заданы, показывается демонстрационный макет. После замены всех визуалов проекта поставьте `demoVisuals: false`.

Показатели помечены как демонстрационные. Меняйте `demo` на `false` только после замены чисел, периода и подтверждения источников. Диаграмма обращений является демонстрационной и автоматически скрывается при `demo: false`; настоящий скриншот аналитики можно добавить через `evidenceImage` и `evidenceAlt`. Конверсия: заявки / посетители × 100%; стоимость заявки: расходы / заявки. Не используйте вымышленные отзывы.

Общие стили: `src/styles/global.css`. Палитра задана CSS-переменными в начале файла.

## Проверки

```sh
npx playwright install chromium webkit
npm test
```

Тесты проверяют семь страниц на пяти ширинах в Chromium и WebKit, порядок кейсов, пагинацию, меню, FAQ, ссылки, доступность и 404. Скриншоты сохраняются в `artifacts`, отчёт в `playwright-report`.

## Публикация

Сборка размещается в `dist/`. Sites project ID хранится в `.openai/hosting.json`. Повторно создавать проект Sites не нужно. Перед сохранением версии отправьте точный коммит в закреплённый репозиторий, соберите архив с `dist/` и `.openai/hosting.json`, сохраните версию, затем опубликуйте и проверьте её статус. Токены доступа в репозиторий не сохраняйте.

Публичный адрес: https://bakeevx.harvincadag811.chatgpt.site

## Визуальные материалы

Фотографии-заглушки: Porsche и Сеул (Unsplash, исходные URL в `docs/assets.md`), фото процесса оклейки из предоставленного локального проекта. Оригинальные фотографии и реальные результаты нужно заменить перед окончательной презентацией соответствующих кейсов.


Хедер закреплён при прокрутке и использует полупрозрачное стекло. Без поддержки размытия остаётся непрозрачный читаемый фон. Счётчики на главной запускаются один раз при появлении; при уменьшенном движении или отключённом JavaScript сразу отображаются конечные значения. Число проектов вычисляется по массиву `projects`.

У кейса `bakeevx` реальные скриншоты и показатели структуры сайта. Для обновления скриншотов: соберите сайт, запустите `npm run preview -- --port 4324`, затем `node scripts/capture-portfolio.mjs` и повторите сборку.
