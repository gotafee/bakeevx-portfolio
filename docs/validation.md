# Проверка реализации

26 сентября 2026.

- `npm run check`: 0 ошибок, предупреждений и подсказок.
- `npm run build`: 7 статических страниц, включая 404, и sitemap.
- `npm test`: 16 тестов пройдено в Chromium и WebKit. Вёрстка шести страниц проверена на ширинах 360, 390, 768, 1280 и 1440 px.
- Проверены порядок кейсов, циклическая пагинация, ссылки Telegram, аккордеоны, клавиатурное управление меню, Escape и prefers-reduced-motion.
- Axe: на всех шести страницах нет автоматически обнаруживаемых нарушений WCAG 2 A/AA и 2.1 AA в проверенных сценариях. Автоматическая проверка не заменяет полный аудит доступности.
- Скриншоты всех страниц на 390 и 1440 px просмотрены. Исправлены контраст небольших подписей и кнопок, перенос заголовка FAQ.
- `npm audit`: 0 известных уязвимостей после обновления Astro до 7.3.5.
- Размер статической сборки около 936 КБ, включая локальные шрифты, фото и Open Graph.

Тестирование проходило в браузерных движках с эмуляцией размеров экрана, без физического телефона. Цифры и визуалы кейсов являются демонстрационными.
